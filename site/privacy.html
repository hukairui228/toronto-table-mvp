隐私说明

本页是一份供朋友试用的静态食单，不设账号、登录、个人档案或广告追踪。

筛选与定位

搜索文字、指定用餐时间、经纬度和浏览器定位只在当前页面内存中处理，不发送给使用统计服务，不保存至 Cookie 或 localStorage。关闭或刷新页面后会重置。

可选的两周统计

网站维护者配置 GoatCounter 站点和测试起始日期后，页面仅在指定的两周内统计页面访问与筛选功能使用次数。事件只包含固定功能名称，不包含你输入的关键字、坐标、店名或筛选值。启用 Do Not Track 时，本页不加载统计脚本。未配置时不向 GoatCounter 发送数据。

GoatCounter 使用无 Cookie 的流量统计。即使不使用 Cookie，访问统计请求和网站托管服务仍会收到网络连接所需的信息，例如 IP 地址和 User-Agent；其处理方式请参阅 GoatCounter 隐私政策及 GitHub 隐私声明。本页不把这些资料用于建立个人食客档案。

Google 数据和外部链接

Google Places 请求由维护者在本机运行，前端不持有 API key。点击 Google Maps 外链后会进入 Google 服务，适用 Google 隐私政策。店铺人工备注会作为公开页面内容展示；请勿填写私人联系方式或不打算公开的内容。

如需更正食单或反馈隐私问题，请通过分享页面给你的维护者联系。
